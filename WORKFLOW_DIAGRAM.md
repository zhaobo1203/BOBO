## 六、技术模块说明

### 6.1 核心模块

| 模块 | 文件 | 功能 |
|------|------|------|
| 进程检测 | `wechat_detection.py` | 检测微信进程、获取进程信息 |
| 账号检测 | `wechat_detection.py` | 识别当前登录账号、数据目录 |
| 密钥获取 | `key_v4.py` | V4版本内存扫描获取密钥 |
| 密钥存储 | `key_store.py` | 密钥持久化存储管理 |
| WCDB连接 | `wcdb_realtime.py` | 打开数据库连接、获取会话和消息 |
| 消息存储 | `message_storage.py` | 消息持久化到SQLite |

### 6.2 新增模块

| 模块 | 文件 | 功能 |
|------|------|------|
| 初始化等待器 | `wechat_waiter.py` | 等待微信进程、数据目录、数据库文件就绪 |
| 密钥获取服务 | `key_service_retry.py` | 带重试机制的密钥获取，整合多种获取方式 |
| HOOK注入器 | `hook_injector.py` | 主动模式：监测进程启动并自动注入 |

## 七、错误码定义

| 错误码 | 描述 |
|--------|------|
| ERR_PROC_001 | 未检测到微信进程 |
| ERR_ACCOUNT_003 | 未检测到微信数据目录 |
| ERR_KEY_002 | 密钥获取失败 |
| ERR_WCDB_001 | session.db 未找到 |
| ERR_WCDB_002 | 未获取到数据库密钥 |
| ERR_WCDB_003 | WCDB 连接失败 |

## 八、配置参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| POLL_INTERVAL_DEFAULT | 10秒 | 默认轮询间隔 |
| POLL_INTERVAL_MIN | 5秒 | 最小轮询间隔 |
| POLL_INTERVAL_MAX | 20秒 | 最大轮询间隔 |
| 密钥重试次数 | 3次 | 获取密钥失败后重试次数 |
| 重试间隔 | 3秒 | 每次重试等待时间 |
| 进程等待超时 | 60秒 | 等待微信进程启动的最长时间 |
| 数据目录等待超时 | 30秒 | 等待数据目录创建的最长时间 |
